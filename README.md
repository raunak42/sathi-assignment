# Sathi Assignment

Sathi Assignment for gamification flow.

## Tech stack used

- TypeScript
- React 19
- Vite
- Tailwind CSS
- Framer Motion
- Radix UI
- shadcn/ui
- React Day Picker
- Zod

## Features

- Create reward systems through a modal workflow
- Reward event selection with nested input states
- Reward type selection with commission tier flow
- Optional time-bound rewards with calendar picker
- Disabled-state tooltips and validation handling
- Success notification after reward creation

## Contributing

1. Fork the repo.
2. Clone the forked repo.
3. `cd sathi-assignment`
4. `npm install`
5. `npm run dev`
6. The development server is now running! Make your code contributions and open some PRs!!!
